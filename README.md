Python-Coded Quality Dashboard mit Pareto, SPC, Ishikawa und FMEA unter Zuhilfenahme von streamlit, numpy und anderen nützlichen Python Bibliotheken.
Die App wird über ein Desktop Icon auf einer Linux Partition gestartet und läuft danach im Web Browser.
Für Git Commit und Push wurde ein weiteres Desktop Icon erstellt.
